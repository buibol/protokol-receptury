# Protokół Receptury 1.0.7

## Zmiany

- Dodano automatyczne sprawdzanie dostępności nowej wersji programu przy uruchomieniu.
- Program porównuje zainstalowaną wersję z najnowszym stabilnym wydaniem opublikowanym w GitHub Releases.
- Jeżeli dostępna jest nowsza wersja, użytkownik otrzymuje komunikat z numerem wersji zainstalowanej i najnowszej.
- Dodano przycisk **„Pobierz aktualizację”**, prowadzący do najnowszego instalatora `ProtokolReceptury_Setup.exe`.
- Sprawdzanie aktualizacji działa w tle i nie opóźnia normalnego uruchamiania programu.
- Brak połączenia z Internetem lub chwilowa niedostępność GitHub nie blokuje działania aplikacji i nie powoduje komunikatu błędu dla użytkownika.
- Aktualizacja nie jest instalowana automatycznie — użytkownik sam decyduje o pobraniu i uruchomieniu instalatora.

## Dystrybucja

Od tej wersji w GitHub Release publikowany jest instalator o stałej nazwie:

`ProtokolReceptury_Setup.exe`

Numer wersji identyfikuje tag i wydanie GitHub, np. `v1.0.7`. Wersjonowany plik `ProtokolReceptury_Setup_1.0.7.exe` pozostaje w lokalnym archiwum wydań.
