# Protokół Receptury 1.0.9

## Zmiany

- Przebudowano górny blok pierwszej strony protokołu PDF.
- **Numer apteczny leku** został przeniesiony pod **Nazwę apteki**.
- Po prawej stronie dodano trzy etapy pobierane z KS-AOW:
  - **Przyjęcie** — data, godzina i osoba przyjmująca,
  - **Sporządzenie** — data, godzina i osoba sporządzająca,
  - **Wydanie** — data, godzina i osoba wydająca.
- Dane etapów są pobierane z tych samych informacji, które aplikacja prezentuje w głównym oknie.
- W głównym oknie zmieniono nazwę sekcji:
  - **„Dane receptury”** → **„Dane recepty”**.
- Pozostałe funkcje wersji 1.0.8 pozostają bez zmian.

## Dystrybucja

W GitHub Release publikowany jest instalator o stałej nazwie:

`ProtokolReceptury_Setup.exe`

Wersjonowany plik:

`ProtokolReceptury_Setup_1.0.9.exe`

pozostaje w lokalnym archiwum wydań.
